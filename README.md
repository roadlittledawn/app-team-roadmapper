# App Team Roadmapper

CRUD app for creating and tracking team roadmaps and capacity planning.

## Features

- Team spaces (separate roadmaps per team/role)
- Gantt chart view with expected vs actual timelines
- Customizable project statuses
- Capacity planning with T-shirt sizing framework
- Custom estimation system with historical data
- Customizable time periods (quarterly default)
- Project sequencing and team lead assignment
- Backlog management for future periods
